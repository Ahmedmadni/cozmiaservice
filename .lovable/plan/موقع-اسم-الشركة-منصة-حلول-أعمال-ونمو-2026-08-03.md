# موقع [اسم الشركة] — منصة حلول أعمال ونمو

موقع عربي كامل (RTL) بتصميم حديث وهادئ، مع Lovable Cloud لحفظ الطلبات والنماذج، وبنية جاهزة لإضافة الإنجليزية لاحقًا.

## الهوية البصرية
- لون أساسي كحلي عميق، مع تركوازي هادئ للنمو، ولمسة رملية/ذهبية محدودة.
- خلفية بيضاء دافئة، مساحات واسعة، بطاقات خفيفة، حواف ناعمة.
- خط IBM Plex Sans Arabic بأوزان متعددة عبر `<link>` في الجذر.
- حركات ناعمة (Framer Motion) عند الظهور وعند التمرير فقط — بلا مبالغة.
- كل الألوان كـ tokens في `src/styles.css` ليسهل تغييرها لاحقًا.

## الصفحات
1. الرئيسية (الأولوية القصوى في الجودة): Hero + المشكلة + الحل (المراحل الأربع) + لماذا نحن + كيف نعمل + الحلول حسب مرحلة المشروع + البرامج والأنظمة + قصص النجاح + CTA.
2. من نحن
3. الحلول (نظرة عامة) + صفحات تفصيلية: حلول الشركات الناشئة، الحلول الرقمية، التسويق والنمو، دعم التنظيم والتشغيل
4. مراحل النمو (ابدأ / نظّم / انطلق / نمُ)
5. البرامج والأنظمة (تصنيفات فقط، بلا أسماء منتجات)
6. الكفاءات والفرق
7. قصص النجاح + صفحة تفصيلية لكل مشروع (بيانات تجريبية)
8. مركز المعرفة + صفحة مقال
9. الأسئلة الشائعة
10. مقياس جاهزية المشروع (أداة تفاعلية)
11. تواصل معنا / طلب استشارة أولية
12. سياسة الخصوصية، الشروط والأحكام، نطاق الخدمات والتنبيهات المهنية

## الالتزام النظامي
- لا صياغات توحي بخدمات محاسبية أو ضريبية أو قانونية مرخصة.
- الصياغات المعتمدة: تنظيم، ترشيح أنظمة، تدريب، تنسيق مع مختصين مرخصين، دعم تشغيلي.
- تنبيه مهني هادئ في التذييل + صفحة نطاق الخدمات + أسفل نتائج مقياس الجاهزية.

## مقياس جاهزية المشروع
ثمانية أسئلة متسلسلة بمؤشر تقدم، ثم ملخص إرشادي عام مع توصيات وأولويات، وزر "اطلب مناقشة النتائج" يفتح نموذج التواصل مع إرفاق ملخص الإجابات.

## Lovable Cloud (البنية)
جداول: `contact_requests`، `consultation_requests`، `assessment_submissions`، وجداول محتوى `services`، `case_studies`، `articles`، `faqs`.
- الإدخال العام مسموح (insert) للنماذج فقط، القراءة العامة للمحتوى المنشور.
- القراءة الإدارية عبر جدول أدوار `user_roles` مع دالة `has_role` — أساس لوحة التحكم لاحقًا.
- المحتوى في النسخة الأولى يُعرض من بيانات تجريبية في ملفات `src/data/*` (سهلة الاستبدال)، مع الجداول جاهزة للربط.

## المكونات القابلة لإعادة الاستخدام
`Navigation` (شفاف ثم صلب عند التمرير)، `Footer`، `SectionHeader`، `ServiceCard`، `GrowthStageCard`، `CaseStudyCard`، `FAQAccordion`، `AssessmentQuestion`، `CTASection`، `StatBlock`.

## التقنية وSEO
- TanStack Start + React + TypeScript + Tailwind v4، ملف `dir="rtl"` و`lang="ar"` في الجذر.
- `head()` لكل صفحة بعنوان ووصف وog مستقل + JSON-LD (Organization / Service / FAQPage / Article).
- Mobile First، شبكات مرنة، صور مولّدة تجريدية بدل الصور التجارية.
- `src/data/site.ts` يحتوي اسم الشركة وبيانات التواصل لتعديلها من مكان واحد.
